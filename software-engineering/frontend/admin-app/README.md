# Admin Frontend

**English** | [中文](README.zh-CN.md)

> Vue 2 admin-facing app, served at `http://localhost:8083` by default. It supports book management, reader management, borrowing workflows, admin management, important operation records, and borrowing rankings.

## Run

```bash
npm install
npm run serve
```

## Build

```bash
npm run build
```

## Configuration

The development API base URL is configured in `.env.development` and defaults to `http://127.0.0.1:8088`.
